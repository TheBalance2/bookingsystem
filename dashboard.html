Customize the sequential reservation ID format or reset the counter back to 001

SIC-2026-001

Assigned sequentially across all new Internal, External, and Special bookings (001, 002, 003…). Downloadable PDF Control Numbers automatically match this ID.

Customize ID Format

Update the prefix, year (e.g., for 2027), or starting number for upcoming reservations.

Uppercase letters/numbers before the year (default: SIC)
Change this when transitioning to a new year (e.g., 2027)
Numbers from 1–999 are zero-padded to 3 digits (1 → 001, 2 → 002). Existing bookings keep their already-issued IDs.

Reset Counter to 001

Start numbering back from the first booking (001) at any time.

  • Resets the next booking number back to 001 using the Prefix and Year in the form (SIC-2026-001).
  • Existing bookings in Firestore keep their already-issued Reference IDs untouched.
  • All subsequent Internal, External, and Special bookings will continue from 001, 002, 003, and so on.
